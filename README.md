## English

Unofficial LineageOS 22.2 (Android 15) for the Japanese docomo **Sony Xperia XZ2 Compact SO-05K** (`xz2c`, `lineage_xz2c_dcm`), feature-aligned with the [XZ1 Compact project](https://github.com/yal3ay/xz1c-lineageos-22).

**Pre-release only, not yet tested on a real device.** Read the release notes before installing. Not affiliated with Sony, docomo or LineageOS. Builds are signed with the project's private keys; later releases keep the same keys so the built-in Updater can install them over the air.
