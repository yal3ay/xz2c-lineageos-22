# Security Policy

## Supported versions

Only the current unofficial LineageOS 22.2 build for the Sony Xperia XZ2
Compact SO-05K (`lineage_xz2c_dcm`) is supported. Older builds are not supported.

## Reporting a vulnerability

Please use **GitHub Private vulnerability reporting**:

1. Open the repository on GitHub.
2. Go to **Security** -> **Advisories**.
3. Click **Report a vulnerability**.

Do **not** open a public issue for an unfixed vulnerability.

Please include the device model (SO-05K), the build date and fingerprint, the
reproduction steps, and relevant logs. Remove personal data, device serial
numbers, Wi-Fi credentials, tokens, and signing material before uploading.
